    import Orrery from "orrery";

const client = new Orrery();
const reply = await client.responses.create({
  model: "orrery-3",
  input: "Summarise this week's incidents",
  tools: ["search"],
});

    How it works

    Fast where it can be. Careful where it counts.

    {{illos:orrery-routing}}

    Routed by difficulty

    Each request goes to the smallest model that can answer it well. The hard ones reach orrery-3.

    {{illos:orrery-mention}}

    Answers that cite

    Orrery pulls the closest pages from your sources and marks each claim with where it came from.

    {{illos:orrery-invoice}}

    Asks before it acts

    Agents stop for a yes before they send, book or pay for anything, and show you exactly what they'll do.
